# Security Policy

AgentKB is currently an alpha project intended primarily for local or trusted-network use.

Do not expose the API or MCP server to the public internet without adding authentication, authorization, request limits, and an appropriate deployment boundary. Treat ingested source material and generated workspaces as potentially sensitive.

Please do not disclose security vulnerabilities in public issues. Report them privately to the repository maintainer with a description, reproduction steps, affected component, and any suggested mitigation. Do not include secrets or private source content in the report.

Security support is best-effort while the project is in alpha. Fixes and disclosure timelines will depend on severity and maintainer availability.
